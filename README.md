# JavaScriptFundamentos03

Continuação dos estudos de JavaScript com foco em funcões, métodos de array, objetos, JSON e introdução à programação Orientada a Objetos.

## Objetos

Ao final deste projeto, o aluno deverá ser capaz de:

- Criar e ultilizar funcões;
- Trabalhar com pârametros, argumentos e retornos;
- Utilizar Arrow Functions;
- Criar e manipular objetos;
- Entender o uso de `this`;
